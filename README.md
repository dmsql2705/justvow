# justvow

**우리의 약속은 사랑이 아니었다** — 이벤트 사이트 「그녀의 휴대폰」

2010년대 갤럭시 휴대폰을 열어 보며 이야기 속 비밀을 찾는 인터랙티브 이벤트 페이지입니다.

## 즐기는 법
1. 화면을 밀어 잠금을 해제합니다.
2. **S메모**에서 그녀가 해마다 적어 둔 기록을 읽습니다.
3. **전화** 키패드에 인물과 관련된 '해'를 누르면 비밀 통화가 연결됩니다.
4. 네 사람의 비밀을 모두 들으면 '???'에게서 전화가 걸려 옵니다.

연락처의 '전화 걸기'(캐릭터별 일반 통화 2종), 갤러리(비밀을 찾으면 열리는 사진), 인터넷(선유그룹 사내 인트라넷 익명 게시판)도 둘러볼 수 있습니다.

## 구성
- `docs/index.html` — 페이지 전체 (HTML·CSS·JS 한 파일). 메모, 연락처, 비밀 대사, 통화, 갤러리, 인트라넷 내용은 파일 안 `MEMOS`, `PEOPLE`, `SECRETS`, `CALLS`, `GALLERY`, `INTRA` 데이터에서 고칠 수 있습니다.
- `docs/img/` — 캐릭터 일러스트, 타이틀 로고, 배경 이미지
- 갤러리 사진은 `GALLERY` 항목의 `img` 칸에 `img/파일명.jpg`를 넣으면 표시됩니다.
